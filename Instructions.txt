Run it like this.

**1. Start XAMPP**
Open XAMPP Control Panel and start:

```text
Apache
MySQL
```

**2. Start Backend**
On the backend/scanner device:

```powershell
cd "D:\Sem VIII\Project\CyberShield Innovators\cloud\backend"
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Use `0.0.0.0` if another device will access it. If everything is on one laptop, `127.0.0.1` is also fine.

**3. Set Frontend Env**
In `user/Frontend/.env`:

If frontend and backend are on same device:

```env
VITE_BACKEND_URL=http://127.0.0.1:8000
VITE_WATCHER_URL=http://127.0.0.1:8765
```

If frontend is on a different device:

```env
VITE_BACKEND_URL=http://BACKEND_DEVICE_IP:8000
VITE_WATCHER_URL=http://127.0.0.1:8765
```

Example:

```env
VITE_BACKEND_URL=http://192.168.1.25:8000
VITE_WATCHER_URL=http://127.0.0.1:8765
```

**4. Start Frontend**
On the frontend/user device:

```powershell
cd "D:\Sem VIII\Project\CyberShield Innovators\user\Frontend"
npm.cmd run dev -- --host 0.0.0.0 --port 5174
```

Open:

```text
http://127.0.0.1:5174
```

If opening from another device, use:

```text
http://FRONTEND_DEVICE_IP:5174
```

**5. Optional: Start Folder Watcher**
Only needed if you want Settings page folder monitoring:

```powershell
cd "D:\Sem VIII\Project\CyberShield Innovators\user\watcher"
python folder_watcher.py
```

Then `8765` will be active.
